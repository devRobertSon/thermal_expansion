# 잘린 고리(Split Ring)의 열팽창 시뮬레이션

원형 고리에서 일부가 잘려나간 고리(split ring / C-ring)가 균일하게 가열될 때
바깥 반지름, 안쪽 반지름, 두께, 그리고 잘린 틈의 간격이 어떻게 변하는지
인터랙티브하게 보여주는 단일 페이지 시뮬레이션입니다.

## 실행

GitHub Pages로 배포해서 브라우저에서 바로 확인할 수 있습니다.

### GitHub Pages 활성화

1. GitHub 저장소 페이지에서 **Settings → Pages** 로 이동
2. **Source** 를 `Deploy from a branch` 로 설정
3. **Branch** 를 `claude/thermal-expansion-simulation-fJ3vN` (또는 병합 후 `main`), 폴더를 `/ (root)` 로 지정하고 **Save**
4. 잠시 후 `https://<사용자명>.github.io/thermal_expansion/` 에서 접속

별도의 빌드 단계는 없습니다. 저장소 루트의 `index.html` 한 개로 동작합니다.

### 로컬에서 실행

```bash
# 저장소 루트에서
python3 -m http.server 8000
# 또는 그냥 index.html 을 브라우저로 열기
```

## 조절 가능한 변수

| 변수 | 범위 | 설명 |
|---|---|---|
| 바깥 지름 | 60 – 200 mm | 고리의 바깥 지름 |
| 두께 (radial) | 2 – 40 mm | 바깥 반지름 − 안쪽 반지름 |
| 잘려나간 각도 | 0° – 180° | 고리에서 잘려나간 부채꼴의 중심각 |
| 열팽창률 αΔT | 0 – 30 % | 선형 변형률 (시각적 비교를 위해 과장된 범위) |

## 표시되는 측정값

팽창 전/후 값과 절대·백분율 변화를 함께 보여줍니다.

- 바깥 반지름 R
- 안쪽 반지름 r
- 두께 t = R − r
- 틈 간격 (현의 길이, 바깥쪽 두 절단면 사이 직선 거리)
- 틈 호의 길이 (바깥쪽 호를 따라 잰 거리)

## 물리적 배경

균일한 선형 열팽창에서는 물체의 모든 **길이 차원**이 같은 인수 `(1 + αΔT)`
만큼 늘어납니다. 잘린 고리의 경우:

- 바깥 반지름, 안쪽 반지름, 두께가 모두 같은 비율로 커집니다.
- 잘린 각도는 무차원이므로 변하지 않지만,
  바깥 호의 길이가 늘어나므로 **틈의 현 길이도 같은 비율로 벌어집니다**
  (`gap_chord = 2 R sin(θ/2)` 에서 R 만 바뀜).
- 닫힌 고리 안쪽 구멍이 가열되면 작아질 것이라는 흔한 직관과 달리,
  실제로는 안쪽 반지름도 함께 **커집니다**. 이 시뮬레이션으로 직접 확인할 수 있습니다.
